# PianoTrack v2

konnahi v2 の PianoTrack を単独アプリとして移植。タイマー、記録のカレンダー／一覧、時刻・メモ編集、削除、期間集計、日平均、日・月・年の練習目標と達成度を備えています。

## 配置

既存のルートファイルは変更せず、v2/ のみ追加します。GitHub Pagesでリポジトリ全体を公開すると、従来版は /pianotrack/、新版は /pianotrack/v2/ です。将来の版も v3/ などを追加し、保存キーとmanifestのscope/idを版ごとに分けます。

## v1 からの移行

1. v1 の「設定」→「バックアップを書き出す」でJSONを保存。
2. v2 の「設定」→「バックアップを読み込む」でそのJSONを選択。
3. 件数を確認して「読み込んで置き換える」。

読み込みはv2の記録を置き換えます。「直前の状態に戻す」で取り消せます。v1のファイルと保存データには触れません。v1と同じデータ形式 version 1 / schemaVersion 1を保持しています。目標と表示設定はブラウザに保存され、JSONバックアップの対象は練習記録です。データは端末・ブラウザ・サイトごとに保存され、自動同期はありません。

## 開発・確認

リポジトリルートで `python3 -m http.server 8766` を実行し、http://localhost:8766/v2/ を開きます。ビルドは不要です。
v2 ディレクトリで `npm install`、`npm test`。集計9件、および元のv1書き出し処理→v2読み込み、長時間記録、メモ、保存領域分離、取り消し、不正入力を検証します。
