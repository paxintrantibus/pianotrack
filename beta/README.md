# PianoTrack Beta — 2.1-beta.1

今後の試験版は、この `beta/` ディレクトリで更新します。マニュアルが初期設定です。

## 試し方

1. 設定 → 計測モード →「オート（試験機能）」を選択。
2. タイマー画面で「開始」を押し、マイクを許可します。
3. スマホをピアノの近くに置き、画面を開いたまま練習してください。画面が消えないようにする機能も、対応ブラウザでは利用します。
4. 静かな状態が2分続くと自動一時停止。音が3秒続くと再開します。一時停止から15分で自動終了し、マイクを解放します。「終了」から手動で終えることもできます。

設定で一時停止までの時間を1・2・3・5分から選べます。音量の目安は左ほど敏感です。再開境界は初期値 -42 dBFS、停止境界はその6 dB下です。これは端末が取得した音声信号の相対値で、部屋の騒音計の数値ではありません。

短い無音は練習として数え、一時停止が確定した時点から時間を除外します。休止前の2分をさかのぼって削除しません。誤判定した記録は「記録」で時刻を編集できます。

画面切り替え・ロック・マイク切断・処理の長い中断を検知すると「監視中断」になります。確認できた時点まで保存し、未監視の時間を練習や無音として数えません。「マイクを接続して再開」を押すか、「終了」で終了してください。再読み込み後も同様に、勝手にはマイクを再開しません。

音量判定なので会話・テレビにも反応します。ヘッドホンでの電子ピアノには向きません。録音・音声送信はありません。HTTPSが必要です（開発時のlocalhostを除く）。iPhone/Androidでの実際の演奏音・画面ロック動作・電池消費は実機試用で確認してください。

マニュアルでは4時間以上の計測が残ったままページを開き直すか画面に戻ると、終了日時を確認できます。計測中はモードを変更できません。

## 記録と移行

v1・v2・betaの保存領域は別々です。設定からv1/v2のJSONを読み込めます。betaの記録を置き換えるので、すでに記録があれば先に書き出してください。

休止時間を旧形式でも正しく扱えるよう、オートは連続して計測した区間ごとに別のセッションを保存します。再開すると次のセッションが始まり、「オート計測」というメモが付きます。タイマーには今回の区間の合計を表示します。

JSONは従来のversion 1 / schemaVersion 1を維持します。バックアップ対象は記録とメモで、目標・計測モード・感度設定は含みません。既存版へ戻す場合も記録は置き換えになるため、各版のバックアップを先に保存してください。

## 既存版を残してアップロードする

ZIPを解凍すると `beta/` フォルダができます。GitHubリポジトリのルートに **betaフォルダごと追加** してください。

```
pianotrack/
  index.html              ← 既存v1。そのまま残す
  assets/                 ← 既存。そのまま残す
  icons/                  ← 既存。そのまま残す
  manifest.webmanifest    ← 既存。そのまま残す
  v2/                     ← 既存v2。そのまま残す
  beta/                   ← 今回追加するフォルダ
    index.html
    assets/
    icons/
    ...
```

**betaの中身をルートに展開しないでください。既存ファイルの削除や、サイト全体をbetaだけで置き換える操作もしません。** コミット前の変更一覧が `beta/…` だけになっていることを確認してください。

GitHub Pagesでブランチのルートを公開している場合、公開元はこれまでのままにします。GitHub Actionsでサイトをデプロイしている場合、公開物には既存v1・v2も含むサイト全体が必要です。betaだけをサイト全体のデプロイ成果物にすると既存URLが消えます。コード側から、このような公開物の置き換えまでは防げません。

公開先は既存サイトの `/pianotrack/beta/` です。

## バージョンの独立性

betaは必要なHTML・CSS・JavaScript・画像をすべて内部に持ち、親やv2のファイルを参照しません。保存キーは `piano-practice-…-beta`、ホーム画面登録のmanifest id/start_url/scopeは `./` です。サービスワーカーは登録せず、既存版のキャッシュや保存データを削除しません。

今後、新しい版を追加する場合も専用ディレクトリ内に資産をコピーし、保存キーを専用に変更します。betaの継続更新ではbeta用キーを維持します。

## 検証

`npm ci` の後、`npm test`。静的アプリなので公開時のビルドやnpmの実行は不要です。ローカルではbetaディレクトリで `python3 -m http.server 8767 --bind 127.0.0.1` を実行すると単独で試せます。

状態遷移、監視中断、保存と再読み込み、マイク拒否（モック）、旧データ読み込み、既存版の保存キー保護、日またぎ集計、資産参照の独立性を自動テストしています。マイク判定は模擬音量で検証しており、実際のピアノ音による感度調整はこれからの試用対象です。
