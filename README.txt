PianoTrack Version 1.0

GitHub Pages などのサーバーには、この PianoTrack フォルダ内の構成を保ったままアップロードしてください。

- index.html
- manifest.webmanifest
- icons/
- assets/piano-rabbit.png

スマートフォンのホーム画面への追加：
- iPhone / iPad：Safari の共有ボタン →「ホーム画面に追加」
- Android：Chrome のメニュー →「ホーム画面に追加」または「アプリをインストール」

設定画面の「About PianoTrack」から、バージョン情報とクレジットを表示できます。
About 画面のイラストには、PNG 版の「ピアノを弾くウサギ」を使用しています。

データ保存形式：schemaVersion 1
従来の配列形式のローカルデータとバックアップも引き続き読み込めます。既存データは、次に記録・編集などで保存するときに新形式へ移行します。
